# Code of conduct

FloatDock is a small project and the discussions around it should stay easy to join.

- Be kind and assume good intent. Argue about the code and the design, not about people.
- Keep issues and pull requests on topic and give enough detail for someone else to act on them.
- No harassment, insults, or personal attacks, and nothing that targets someone for who they are.
- Do not post other people's private information.

The maintainer may edit or remove comments, lock threads, and block people who break these rules. To report a problem with someone's behavior, write to the maintainer through the contact link on [github.com/Simifar](https://github.com/Simifar). Report security problems privately as described in [SECURITY.md](SECURITY.md).
